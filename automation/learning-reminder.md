# Learning reminder task

Use this as the prompt for a scheduled task associated with this local project:

> Read `AGENTS.md` and the private `.learning/plan.md`. Do not quote, publish, stage, commit, or copy private-plan content into public files, issues, or messages. Identify the highest-priority unchecked learning outcome and remind me what to do next in no more than five lines. Mention any private due date only as a relative urgency such as "due soon" or "overdue." Check the public `learning-progress.json` and recent Git history so the reminder reflects completed work. If the plan is complete or needs a decision, ask one concise question. Do not modify files.

Recommended starting cadence: Monday, Wednesday, and Friday at 9:00 AM in the owner's local timezone. Test the prompt manually before enabling the schedule.

For a fully online task that cannot access this checkout, privately upload the plan or store it in a private connected source. Do not copy the plan into this public repository. Remember that an uploaded copy will not automatically follow later local edits.
